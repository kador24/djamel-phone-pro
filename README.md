# جمال فون | Jamal Phone

واجهة متجر عربية RTL لعرض الهواتف والإكسسوارات والمنتجات التقنية، مصممة للنشر على GitHub Pages. ملفات الواجهة ثابتة ولا تحتاج إلى خادم أو حزم خارجية.

## تشغيل المتجر محليًا

يتطلب Python 3. افتح الطرفية داخل مجلد `jamal-phone` وشغّل:

```bash
python3 -m http.server 8000
```

ثم افتح `http://localhost:8000`. يلزم خادم محلي لأن الموقع يقرأ ملفات JSON باستخدام `fetch`؛ لا تفتح `index.html` مباشرة من مدير الملفات.

## نشر GitHub Pages

ارفع محتويات هذا المجلد إلى مستودع GitHub، ثم فعّل **Settings → Pages** للمستودع. المسارات نسبية حتى يعمل المتجر على نطاق GitHub Pages وعلى المسارات الفرعية. يستبعد إعداد Jekyll مجلد `admin` من ملفات الموقع المنشورة. استبدل `YOUR-DOMAIN` في `sitemap.xml` و`robots.txt` بنطاق النشر قبل إرسال خريطة الموقع إلى محركات البحث. روابط Canonical وبيانات الصفحة الوصفية تتكيّف مع رابط الصفحة المنشورة.

## المنتجات ولوحة الإدارة

- يبدأ الكتالوج فارغًا عمدًا؛ لا يحتوي المشروع على أسعار أو منتجات مختلقة. أضف المنتجات الحقيقية من لوحة الإدارة.
- تعمل اللوحة من المجلد `admin` بصورة مستقلة عن المتجر: `cd admin && node server.js`، ثم افتح `http://localhost:5173`.
- تتطلب اللوحة Node.js 18 أو أحدث. إعدادها وحفظ المحتوى على GitHub مشروحان في `admin/README.md`.
- أضف سعر المنتج والسعر الأصلي في حقل **Original price (offer)** لإظهار الخصم في قسم العروض. لا يظهر خصم إلا عندما يكون السعر الأصلي أعلى من السعر الحالي.
- حقول العنوان والهاتف وواتساب والخرائط ومواعيد العمل اختيارية، وتظهر للزوار بعد ضبطها في إعدادات المتجر.

تُحسّن لوحة الإدارة صور المنتجات إلى أحجام WebP متعددة، وتحمّل الواجهة الصور عند الحاجة لتقليل حجم الصفحة. لا تضع إعدادات الإدارة أو رموز GitHub أو أي بيانات خاصة داخل ملفات المتجر العامة.
## النسخة الجاهزة للنشر

- يحتوي المشروع على `.nojekyll` حتى لا يعامل GitHub Pages ملفات الكتالوج كملفات Jekyll.
- يوجد workflow في `.github/workflows/pages.yml` لنشر المتجر عبر GitHub Pages عند الدفع إلى `main`.
- مجلد `admin` مستبعد من artifact المنشور؛ يبقى للاستخدام المحلي فقط.
- قسم “عن جمال فون” وقسم “أكثر من هاتف” مرتبطان مباشرة ببيانات `content/home.json` التي تعدلها لوحة الإدارة.
- رابط Google Maps محفوظ في `content/store.json` ويمكن تغييره من لوحة الإدارة.
