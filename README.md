# جمال فون — المتجر الإلكتروني

واجهة عربية RTL لمتجر الهواتف والإكسسوارات والخدمات الرقمية. تستخدم Supabase الحالي للبيانات، وتسجيل دخول الإدارة، وتخزين صور المنتجات. النشر المستهدف Cloudflare Pages بخطة مجانية.

## ما تم بناؤه

- الصفحة الرئيسية وتصنيفات وبطاقات منتجات متجاوبة مستوحاة من بنية عرض المتاجر المرجعية، مع هوية جمال فون.
- صفحات المنتجات والخدمات، وبحث وتصفية حسب التصنيف.
- زر «شراء الآن» للمنتجات و«طلب الخدمة» للخدمات؛ يفتح رسالة طلب مهيأة على WhatsApp عند إعداد رقم المتجر.
- لوحة إدارة محمية بتسجيل دخول Supabase، للمنتجات والباركود والصور والفئات وإعدادات المتجر.
- حقول طلب قابلة للتخصيص لكل خدمة (مثل اسم الحساب أو نوع الخدمة أو تفاصيل الشراء).
- لا توجد سلة أو بوابة دفع إلكتروني أو حسابات للزبائن في الواجهة العامة.

## الإعداد المحلي والاختبار

1. شغّل `npm install` لتثبيت الحزم.
2. للتطوير المحلي، انسخ `.env.example` إلى `.env.local` وتأكد من قيم Supabase.
3. شغّل `npm test` لاختبارات المساعدات (أرقام WhatsApp، الرسائل العربية، الروابط المختصرة، حقول الخدمات، الصور والإعدادات).
4. شغّل `npm run typecheck` ثم `npm run build` قبل النشر.

ملف `.env.production` يتضمن رابط Supabase ومفتاح **Publishable** العام حتى تعمل نسخة الإنتاج عند البناء. هذا المفتاح مصمم للاستخدام في الواجهة؛ لا تضع مفتاح `service_role` أو أي مفتاح سري في المتصفح أو المستودع.

## النشر على Cloudflare Pages

- اربط مستودع GitHub بهذا المشروع.
- Build command: `npm run build`
- Build output directory: `dist`
- تم تضمين إعدادات Supabase العامة في `.env.production`؛ ويمكن تجاوزها من إعدادات البيئة لدى Cloudflare Pages باستخدام `VITE_SUPABASE_URL` و`VITE_SUPABASE_PUBLISHABLE_KEY`.
- ملف `public/_redirects` يعيد توجيه روابط الصفحات إلى تطبيق React.
- نفّذ الاختبارات والبناء محليًا أولًا، ثم ارفع الملفات بنفسك.

## الإدارة

- افتح `/admin/login` وسجّل الدخول ببريد وكلمة مرور حساب المدير الموجود في Supabase.
- يجب أن يكون دور الحساب `admin` في `public.profiles`.
- اضبط رقم WhatsApp بصيغة دولية أو رقم جزائري يبدأ بصفر من صفحة «إعدادات المتجر».
- صور المنتجات تُرفع إلى حاوية `product-media`، ثم تُربط بجدول `product_images`.

## قاعدة البيانات

المشروع يستخدم الجداول الموجودة؛ أضيف فقط الحقلان `item_type` و`service_fields` لتمييز الخدمات وحفظ حقول الطلب الخاصة بها. لا يحتاج مفتاحًا سريًا في المتصفح.
